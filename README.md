# Personal Portfolio Website

The personal portfolio website for Joseph Mugambi Ndwiga, showcasing expertise in software engineering, DevOps, and AI/ML.

## Live Links

- **Portfolio:** [https://zombimann.github.io](https://zombimann.github.io)
- **Zoom Bee:** Currently undeployed. Undergoing refinement and expansion prior to production deployment.

## Overview

A lightweight, static website designed to present professional experience and technical projects cleanly across all devices.

### Contents
- **Professional Summary & Skills:** Breakdown of core engineering competencies, frameworks, and cloud tooling.
- **Work & Projects:** Selected software, data, and visualization projects.
- **Responsive Layout:** Built with modern CSS Grid and Flexbox for fluid mobile, tablet, and desktop viewing.
- **Print Stylesheet:** Custom CSS for generating a clean, printable resume format.

## Tech Stack

- HTML5
- CSS3 (Flexbox & CSS Grid)
- JavaScript

## Local Development

```bash
# Clone the repository
git clone [https://github.com/zombimann/zombimann.github.io.git](https://github.com/zombimann/zombimann.github.io.git)
cd zombimann.github.io

# Start local server
python -m http.server 8000

```

Open `http://localhost:8000` in your browser to view the site.
